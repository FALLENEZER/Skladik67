# Система учёта склада - архитектурный репозиторий

Архитектурный репозиторий - это средство управления архитектурной документацией, где хранится вся информация о структуре, стандартах и правилах системы.

Предмет репозитория - **Система учёта склада**: заказы поставщикам, доставка собственным транспортом с GPS-мониторингом, приёмка товара с проверкой качества, учёт остатков.

Основан на шаблоне [qasmark/project-doc](https://github.com/qasmark/project-doc).
